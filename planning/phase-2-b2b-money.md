# Phase 2 — B2B and money automation (1–2 months)

**Gate:** 10 active agencies; supplier payouts done in one weekly click.

- [ ] **2.1 Agency registration** — company details, trade licence upload, admin approval, agreement e-sign.
- [ ] **2.2 Agent portal** — dashboard (orders by status, wallet balance, monthly spend), B2B net price list, apply for a client (passenger data; client contact stays the agent's).
- [ ] **2.3 Bulk/group applications** — one order, many applicants, CSV import.
- [ ] **2.4 Agency sub-users** — agency admin invites staff; per-user permissions.
- [ ] **2.5 Wallet** — top-up via bank transfer (admin confirms), bKash, card; instant deduction on order; statement; ledger entries per `accounting-rules.md`.
- [ ] **2.6 Credit limits** — per agency limit, due terms, overdue auto-block, ageing report.
- [ ] **2.7 Tiers** — Silver/Gold/Platinum markups; automatic monthly upgrade/downgrade by volume; manual override.
- [ ] **2.8 White-label PDFs** — invoices and status PDFs with the agency's logo and details instead of Govoyza's.
- [ ] **2.9 Commission reports** for agencies.
- [ ] **2.10 Supplier payout batches** — payables become due on completion (+ configurable holding period); weekly batch built automatically; Finance/Owner approves once; statements emailed to suppliers; ledger posting.
- [ ] **2.11 Reconciliation** — import gateway settlement CSVs and bank statement CSVs; auto-match to ledger; only mismatches shown.
- [ ] **2.12 Expenses** — simple form (rent, ads, salaries, software) posting to expense accounts; receipt upload.
- [ ] **2.13 SMS notifications** — Bangladeshi SMS gateway adapter; templates per event.
- [ ] **2.14 WhatsApp notifications** — WhatsApp Business API (via Meta Cloud API or a BSP); approved templates per event.
- [ ] **2.15 Accountant access** — read-only role; exports to Excel and accounting software format (Tally/QuickBooks/Xero/Zoho Books CSV).
